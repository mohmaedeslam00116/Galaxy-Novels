# تحديث أمان البيانات قبل النشر

أضيف Google Analytics for Firebase إلى تطبيق Android ضمن مشروع
`galaxy-novels-app-4720`. لذلك يجب مراجعة نموذج «أمان البيانات» في Google Play
قبل إرسال الإصدار التالي، وعدم الاعتماد على الإجابات القديمة.

يستخدم التطبيق أيضًا Firebase Crashlytics لتقارير الأعطال والتشخيصات، وFirebase
Remote Config لتوزيع سياسة دعم الإصدارات ورسائل التحديث. يجب أن تذكر سياسة
الخصوصية جمع بيانات الأعطال والتشخيص ومعرّفات التثبيت التي تستخدمها حزم Firebase
وفق إفصاحات Google الحالية.

## الحد الأدنى الواجب مراجعته

- اختيار أن التطبيق يجمع أو يشارك بعض أنواع البيانات.
- مراجعة «نشاط التطبيق / التفاعلات داخل التطبيق» لغرض التحليلات.
- مراجعة «الجهاز أو معرّفات أخرى» وفق إفصاح Firebase Analytics وGoogle Mobile Ads.
- مراجعة «الأعطال والتشخيصات» بسبب Firebase Crashlytics.
- إبقاء «الإعلانات أو التسويق» لبيانات AdMob ذات الصلة.
- تأكيد التشفير أثناء النقل بعد التحقق من جميع خدمات التطبيق وSDKs.
- مطابقة الإجابات مع أحدث صفحات Data Safety المنشورة من Firebase وAdMob.

الأحداث المخصصة للتنزيل لا ترسل اسم الرواية أو الفصل أو نصه أو معرّف الحساب؛
تقتصر على الأعداد، حالات العملية، نوع الاختيار، وعلامة مستوى العضوية.

## خطوات لوحة Google المتبقية

1. ربط مشروع Firebase بتطبيق AdMob من لوحة AdMob.
2. تفعيل Consent Mode في لوحة AdMob؛ Firebase يبدأ قبل UMP داخل التطبيق.
3. تحديث سياسة الخصوصية المنشورة على الموقع لتطابق النص داخل التطبيق.
4. جمع خط أساس لمدة 14 يومًا قبل اتخاذ قرار الوساطة أو إضافة شبكة إعلانية.
