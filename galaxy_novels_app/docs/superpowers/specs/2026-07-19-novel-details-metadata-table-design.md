# تصميم جدول بيانات تفاصيل الرواية

## الهدف

استبدال شبكة معلومات الرواية الحالية ذات الأعمدة المتعددة ببطاقة رأسية أوضح للقراءة العربية، خصوصًا عندما تكون أسماء الكاتب أو المترجم طويلة أو عند تكبير النص.

## النطاق

يتغير عرض الحقول الأربعة التالية فقط داخل رأس صفحة تفاصيل الرواية:

1. الكاتب.
2. المترجم.
3. عدد الفصول.
4. التقييم.

لا تتغير مصادر البيانات أو منطق التقييم أو تسجيل الدخول أو بقية أقسام الصفحة، ولا تعود أي وظيفة متعلقة بالتنزيلات.

## التكوين البصري

- تعرض الحقول داخل بطاقة واحدة مستديرة الزوايا بلون السطح المعتمد في صفحة التفاصيل.
- ترتب الحقول في أربعة صفوف رأسية تفصل بينها خطوط رفيعة.
- يحتوي كل صف من جهة البداية على أيقونة داخل دائرة بنفسجية خفيفة، ثم اسم الحقل، ثم قيمته في المساحة المتبقية.
- تسمح قيمتا الكاتب والمترجم بسطرين مع اقتطاع آمن إذا تجاوزتا ذلك.
- تعرض القيمة `غير متوفر` عندما يكون الكاتب أو المترجم فارغًا، كما في السلوك الحالي.
- يحافظ الجدول على حد أدنى 48 بكسل للعناصر التفاعلية ويتكيف مع تكبير النص حتى 200%.

## صف التقييم

- يكون التقييم هو الصف الرابع والأخير داخل البطاقة نفسها.
- يتميز الصف بخلفية بنفسجية خفيفة دون فصله في بطاقة مستقلة.
- يعرض التقييم العام وعدد التقييمات وحالة المستخدم الحالية، بما فيها `تقييمك: X من 5` بعد الحفظ.
- يظهر رمز استفهام صغير مع التلميح `اضغط لإضافة أو تعديل تقييمك`.
- يكون الصف كاملًا قابلًا للضغط.
- للضيف يفتح مسار الحساب، وللمستخدم المسجل يفتح محرر التقييم، وعند فشل تحميل حالة التفاعل يعيد الضغط المحاولة. أثناء التحميل أو الإرسال يكون الصف معطلًا كما هو حاليًا.

## الألوان والاتجاه

- يستخدم الوضع الداكن ألوان Stitch المعتمدة حاليًا في صفحة التفاصيل دون تغيير.
- يستخدم الوضع الفاتح الرموز اللونية الحالية المقابلة.
- يعتمد التخطيط `Directionality` الخاص بالتطبيق، لذلك يظهر ترتيب الصفوف صحيحًا في العربية دون قيم ثابتة لليمين واليسار.

## الاختبارات ومعايير القبول

- تظهر بطاقة واحدة وأربعة صفوف بالترتيب المعتمد.
- لا تبقى شبكة 2×2 أو بطاقات منفصلة للمعلومات.
- يعمل ضغط صف التقييم في حالات المستخدم المسجل والضيف والفشل.
- يبقى تلميح علامة الاستفهام وتقييم المستخدم ظاهرين.
- لا يحدث تجاوز بصري عند عرض 320 و600 و840 بكسل أو عند تكبير النص إلى 200%.
- تمر اختبارات الصور المرجعية للوضعين الداكن والفاتح بعد تحديث صور صفحة التفاصيل فقط.
- لا يظهر أي رمز أو إجراء تنزيل في الصفحة.
